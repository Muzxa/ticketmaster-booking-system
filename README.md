# Event Management System

React starter for Web Programming Assignment 2, with Bootstrap, React Router, Redux Toolkit, Vite, ESLint, Prettier, and Vitest dependencies.

## Development

Use Node.js 22.12+ (or 20.19+) and npm.

```sh
npm install
npm run dev
```

## Commands

- `npm run build`: create the production bundle in `dist/`.
- `npm run preview`: preview the production build.
- `npm run lint`: check source code.
- `npm run format`: format project files.
- `npm test`: run tests when added.

Application features and API configuration will be added separately.
